# Карьер — живой прототип

Демо для встречи с заказчиком: один рейс от CRM до закрытия наряда.

Для встречи можно сразу открыть `standalone.html` в браузере — сценарий тот же, установка не нужна.

Либо Vite-версия:

```bash
npm install
npm run dev
```


Пульт сверху ведёт сценарий по шагам. Экраны весовой, водителя и погрузчика обновляются вместе.
