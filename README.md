# Карьер — живой прототип

Демо для встречи с заказчиком: один рейс от CRM до закрытия наряда.
Пульт ведущего ведёт сценарий по шагам, экраны весовой, водителя и погрузчика
обновляются синхронно.

## Быстрый старт

Для встречи можно сразу открыть `standalone.html` в браузере — тот же сценарий,
установка не нужна. Файл генерируется из исходников, см. «Сборка».

Либо Vite-версия:

```bash
npm install
npm run dev
```

## Сценарий

1. Заказ из CRM
2. Камера ANPR: въезд, наряд найден, светофор зелёный
3. Взвешивание тары
4. Пуш водителю с номером поста погрузки
5. Погрузчик подтверждает загрузку
6. Камера ANPR: выезд, брутто/нетто, наряд закрыт, продажи уведомлены

Управление:

- кнопки шагов в таймлайне или большая кнопка «Следующий шаг»;
- **Авто-демо** — прогон сценария с паузами (кнопка «Пауза» останавливает);
- горячие клавиши: `Space` / `→` — следующий шаг, `R` — сброс;
- после закрытия наряда показывается сводка рейса с длительностью этапов.

## Сборка

```bash
npm run build            # tsc --noEmit + vite build в dist/
npm run build:standalone # build + инлайнинг в standalone.html рядом с index.html
```

`standalone.html` — генерируемый файл: скрипт `scripts/build-standalone.mjs`
вшивает JS и CSS из `dist/` в один HTML, который работает по `file://`.
Правки нужно вносить в `src/`, а не в `standalone.html`.

## Структура

- `src/model.ts` — типы, данные наряда и сценария, селекторы, правила шагов;
- `src/demo.ts` — reducer и action creators (чистые, без времени внутри reducer);
- `src/hooks.ts` — авто-демо, горячие клавиши, анимация счётчиков, пульс ANPR;
- `src/PresenterBar.tsx`, `src/Stepper.tsx`, `src/RouteMap.tsx` — пульт ведущего;
- `src/OperatorDesk.tsx`, `src/DriverPhone.tsx`, `src/LoaderTablet.tsx` — экраны ролей;
- `src/TripSummary.tsx`, `src/icons.tsx`, `src/index.css` — сводка, иконки, стили.
